理解边界：
1. intent 保留 WAH 自然语言任务目标，不输出动作序列。

3. WAH 官方目标通常是类级关系；understanding 可以选目标类别和候选实例，但必须标明数量约束。
4. skill_closure 只能使用 WAH skills root 中启用的 skill，例如 go_to、pick_up、put_down、open、close、turn_on、turn_off、clean。
