---
name: Pickup
description: 用机械臂抓取目标物品。执行前需确保机械臂空闲，且物品未被锁在关闭的容器内。
---


## 参数
| 参数 | 类型 | 说明 |
|------|------|------|
| target_item | string | 待抓取的物品唯一ID，如：`水果刀_1`、`苹果_1` |

## 前提条件
* **【位置前提】** 机器人必须已到达 `target_item` **直接所在的容器、设施或表面**；如果 `target_item` 位于容器内部组件中，也允许机器人位于其父链上的已打开可交互节点前方。严禁只在“厨房”等大区域内尝试隔空抓取。
* **【单臂约束绝对红线】** 机器人只有一只机械臂，执行前必须确认机械臂为空（`is_hand_empty: True`）。严禁手里有东西时执行抓取。
* **【物理可达性前提】** 如果 `target_item` 存放在闭合类容器（如冰箱、抽屉、橱柜等）内部，该容器当前属性必须为 `isOpen: True`。严禁穿模抓取封闭容器内的物品。

## 后果
* 机器人的机械臂状态变更为持有 `target_item`。

## 示例
```json
{
  "state_awareness": {
    "current_location": "冰箱_1",
    "current_held_item": "空"
  },
  "pre_flight_checks": [
    "检查：苹果_1 的直接所在位置是 冰箱_1，当前位置正好是 冰箱_1，满足位置前提",
    "检查：当前手里没有拿东西，满足单臂抓取前提",
    "检查：苹果_1 位于 冰箱_1 内，且 冰箱_1 门已打开（isOpen: True），满足物理可达性"
  ],
  "execution": {
    "skill": "Pickup",
    "parameters": {
      "target_item": "苹果_1"
    }
  }
}
